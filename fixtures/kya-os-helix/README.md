# Cross-language KYA-OS fixtures (helix-sdk-js owned)

`needs-authorization.json` (story L3-E): signed `needs_authorization` challenges as
`@helixid/mcp-middleware` answers them, each with the outcome `handleNeedsAuthorization`
must reach at `now` against the service DID document, plus the retry params `withResume`
builds. Generated by `helix-sdk-js/tests/unit/kyaos/needs-authorization.test.ts` from a
fixed test key, nonce and clock:

    HELIX_WRITE_FIXTURES=1 npx vitest run tests/unit/kyaos/needs-authorization.test.ts

helix-sdk-py reads the same file from the sibling checkout
(`../helix-sdk-js/fixtures`, or `HELIX_SDK_JS_FIXTURES_DIR`). The story's fixture set
would normally live in helix-core (`fixtures/kya-os-helix/`, stories rule 6); it lives
here because helix-core is not in L3-E's PR set.
